# Portal de Casamento - Joara & Gabriel

Bem-vindo ao repositório do site de casamento de Joara & Gabriel! Este projeto é um frontend moderno e responsivo desenvolvido para celebrar nossa união, compartilhar nossa história e gerenciar nossa lista de presentes.

## 🌟 Funcionalidades

- **Home Experience**: Uma página inicial imersiva com contagem regressiva, história do casal, e detalhes do evento.
- **Lista de Presentes Interativa**: Uma seleção curada de 100 presentes criativos (de cotas para lua de mel a itens divertidos para o dia a dia), com paginação e busca visual.
- **Design Responsivo**: Totalmente adaptado para mobile, tablet e desktop.
- **Integração de Pagamento Simplificada**: Redirecionamento direto para links de pagamento (Mercado Pago, etc) configurados para cada presente.

## 🚀 Tecnologias Utilizadas

- **React 18** + **Vite**: Para uma experiência de desenvolvimento rápida e performática.
- **TypeScript**: Para tipagem segura e código mais robusto.
- **CSS3 / CSS Modules**: Estilização personalizada com variáveis CSS para fácil manutenção do tema.
- **Swiper.js**: Carrossel de fotos interativo.
- **Lucide React**: Ícones leves e bonitos.
- **React Router DOM**: Navegação SPA (Single Page Application).

## 🛠️ Instalação e Execução

Siga os passos abaixo para rodar o projeto localmente:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/casamento-portal.git
   cd casamento-portal
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Build para produção:**
   ```bash
   npm run build
   ```

## 📂 Estrutura do Projeto

- `src/components`: Componentes reutilizáveis (GiftCard, Navbar, etc).
- `src/pages`: Páginas principais (Home, Gifts, Confirmation, etc).
- `src/data`: Dados estáticos (lista de presentes em `gifts.ts`).
- `src/services`: Utilitários de serviço (lógica de pagamento).
- `src/assets`: Imagens e fontes.
